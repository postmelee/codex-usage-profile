# Task M100 #55 수행계획서

GitHub Issue: [#55](https://github.com/postmelee/codex-usage-profile/issues/55)
마일스톤: M100

## 목적

랜딩 카드가 session과 owner profile을 확인하는 동안 이전 owner 카드나
완성되지 않은 새 이미지를 잠깐 노출하지 않도록 한다. 고정된 카드 비율을
유지하는 skeleton loading 상태를 제공하고, owner preview 이미지가
preload와 decode까지 완료된 뒤 한 번만 교체한다.

anonymous 랜딩의 실제 예시는 서비스 운영자 `postmelee`의 stable public
card로 명시하되, public card가 private/unpublished이거나 `404`/`503`,
decode 실패인 경우 기존 정적 sample로 안전하게 대체한다. logout과 shared
browser에서는 이전 사용자 identity와 preview URL이 남지 않게 한다.

## 배경

현재 `HomePage`는 초기 session 상태에서 정적 sample을 표시하고
`authenticated`가 되면 owner preview URL을 즉시 같은 `<img>`에 대입한다.
session, profile API와 이미지 응답 시점이 서로 달라 브라우저가 새 이미지를
decode하기 전 이전 픽셀을 유지하거나 카드가 갑자기 교체될 수 있다.

Issue #38 이후 랜딩 카드와 Share Studio는 같은 source card ref를 사용한다.
따라서 loading 개선은 홈 카드의 source 선택과 표시 전환에만 한정하고
Share Studio layout/motion을 변경하지 않아야 한다. Issue #55의 수용 기준,
기존 `MarketingLanding`/`HomePage`, profile UI E2E와
`.openai/hosting.json`의 기존 Sites project/D1/R2 linkage를 기준으로 한다.

## 범위

### 포함

- marketing configuration에 운영자 handle `postmelee`와 locale-aware stable
  public card URL을 명시
- 운영자 public card 실패 시 `/assets/codex-card-sample.png` fallback
- session, owner profile, visible image와 pending image 상태를 분리
- 현재 카드 유지, 완전한 skeleton veil, preload/decode 완료 후 단일 crossfade
- profile action의 loading/disabled 상태와 `aria-busy`, live status 제공
- `404`/`503`, 느린 image, decode failure와 stale async completion fail-close
- logout 즉시 운영자 랜딩 상태로 복원하고 owner identity/overlay 제거
- `prefers-reduced-motion`에서 shimmer와 crossfade를 제거한 정적 skeleton
- desktop/mobile/reduced-motion E2E와 screenshot, browser storage 검사
- Home, public profile과 Share Studio 회귀 검증

### 제외

- Share Studio #38의 layout, motion, share action 또는 dialog 변경
- stable card endpoint, renderer, D1/R2와 backend API 계약 변경
- 여러 featured card 선택 또는 운영자 admin UI
- 이전 로그인 owner handle, avatar 또는 preview URL의 browser storage 저장

## 설계 방향

- **운영자 카드 설정**: `profile-marketing/marketing-config.js`에
  `postmelee` handle을 non-secret product configuration으로 고정하고,
  현재 origin의 `/u/postmelee/card.png?locale={en|ko}` 상대 URL을 만든다.
  external origin, credential, owner id 또는 D1/R2 조회를 client config에
  넣지 않는다.
- **초기 fallback**: 새 document의 첫 image는 운영자 stable card를
  요청하되 media box 전체를 중립 skeleton으로 덮는다. 운영자 image가
  실패하면 정적 sample을 preload/decode한 뒤 같은 box에서 표시한다.
- **전환 상태 머신**: visible source와 pending source를 분리하고 각 load에
  generation/token을 부여한다. session/profile/logout이나 locale 변경으로
  target이 바뀌면 이전 load 완료는 무시한다.
- **owner preview gate**: authenticated owner preview는 owner profile
  준비와 image preload/decode가 모두 끝난 뒤에만 visible card가 된다.
  데이터 준비 전 profile action은 disabled/loading을 유지한다.
- **identity reset**: logout 또는 anonymous 전환 시 owner preview,
  personalized sample overlay와 pending load를 즉시 폐기한다. React state
  외 browser storage, URL, cookie 또는 global cache에 identity를 저장하지
  않는다.
- **motion personality**: 제품의 기존 clean dashboard 톤에 맞춘 Corporate
  motion을 사용한다. skeleton shimmer는 진행 상태만 전달하는 낮은 대비의
  ambient loop, ready 교체는 opacity 중심의 약 240ms
  `cubic-bezier(0.2, 0, 0, 1)` crossfade로 제한한다. layout/position은
  움직이지 않는다.
- **privacy veil**: skeleton은 반투명 장식이 아니라 카드 content를 완전히
  가리는 neutral surface로 두어 이전 사용자 identity가 loading 중
  비치지 않게 한다.
- **reduced motion**: media query에서 shimmer, crossfade와 tilt/beam의
  loading motion을 제거하고 동일한 `aria-busy`/status 의미를 정적
  skeleton으로 전달한다.
- **Sites 경계**: 기존 Sites capability path, Vite/Worker 구조와
  `.openai/hosting.json`을 보존한다. 이번 task는 build/artifact까지만
  검증하고 이슈의 명시적 제외 범위에 따라 production deploy는 수행하지
  않는다.

## 리스크

- **stale image race**: 이전 owner/image request가 늦게 완료돼 새 state를
  덮을 수 있다. generation token과 effect cleanup으로 current target만
  commit한다.
- **shared-browser identity 노출**: 기존 decoded image나 personalized
  overlay가 session loading/logout 뒤 보일 수 있다. full-content skeleton,
  immediate owner state reset과 storage 금지로 차단한다.
- **operator card unavailable**: 운영자 profile이 private/unpublished이거나
  R2가 일시 실패할 수 있다. public endpoint 응답 종류를 구분하지 않고
  static sample로 fail closed한다.
- **layout shift**: 두 image element나 overlay가 box 크기를 바꿀 수 있다.
  기존 499:306 aspect ratio와 absolute layers를 유지하고 bounding box를
  E2E로 비교한다.
- **과도한 motion**: shimmer와 crossfade가 loading을 산만하게 만들 수
  있다. Corporate easing, 낮은 대비와 최소 property를 사용하고
  reduced-motion에서는 animation을 제거한다.
- **Share Studio source ref 충돌**: landing source card가 전환 중일 때
  Share handoff가 잘못된 image를 참조할 수 있다. action ready gate와 기존
  `cardTransitionSuspended` 경계를 유지해 loading 중 Share를 금지한다.
- **배포 범위 오인**: Sites build가 성공해도 이번 task는 production
  deploy/access 변경을 승인하지 않는다. 배포는 별도 지시와 승인에서만
  수행한다.

## 승인 요청 사항

- 운영자 example을 `postmelee` stable public card로 고정하고 locale-aware
  same-origin URL과 static sample fallback을 사용하는 방향
- visible/pending image와 generation token을 분리해 preload/decode 완료
  후에만 owner preview를 교체하는 방향
- content를 완전히 가리는 neutral skeleton, 낮은 대비 shimmer와 약
  240ms Corporate crossfade, reduced-motion 정적 대체 표현
- browser storage에 owner identity/preview URL을 저장하지 않고 logout에서
  즉시 폐기하는 privacy 경계
- 4개 Stage, 예상 변경 파일과 공식 문서 미변경 판단
- production Sites deploy/access를 제외하고 local build/artifact와 E2E까지
  수행하는 범위

승인되면 `task_m100_55_impl.md`에서 단계별 산출물, 검증 명령, 커밋
메시지를 구체화한다.
